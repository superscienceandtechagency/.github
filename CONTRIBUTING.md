# Contributing

This repository contains the public profile and service documentation for Super Science & Technology Agency. It is not currently a software product repository.

Documentation corrections and profile improvements may be proposed if the agency chooses to accept them. Please keep suggestions factual, evidence-based, and consistent with the source service catalog. Do not add unverified team details, project claims, credentials, or contact information.

See the [organization profile](./profile/README.md) and [service catalog](./SERVICES.md).
