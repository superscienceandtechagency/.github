# Contributing

This repository hosts the public profile and service catalog for Super Science & Technology Agency. Contributions should support the organization profile, improve clarity, and remain accurate and evidence-based.

## How to contribute

- Keep content factual and source-derived.
- Prefer verified public information over assumptions or placeholder claims.
- Update the homepage and service catalog together when scope or wording changes.
- Use clear Markdown with accessible headings and consistent terminology.
- Keep pull requests focused on a single improvement or update.

## Content standards

- Do not invent people, client work, credentials, achievements, or deployment details.
- Do not add unsupported metrics, business claims, or unverified product statements.
- If information is missing, mark it as pending rather than guessing.
- Preserve the numbering, wording, and service categories supplied in the source catalog.

## Suggested workflow

1. Review the current profile and service catalog.
2. Make a focused documentation change.
3. Check links and formatting.
4. Open a pull request with a brief summary of the change.

## Repository layout

- `profile/README.md` provides the public organization homepage.
- `SERVICES.md` contains the complete service catalog and engagement information.
- This document provides contributor guidance for the repository.
